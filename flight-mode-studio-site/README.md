# Flight Mode Studio Landing Page

A deploy-ready Next.js + Tailwind landing page for Flight Mode Studio, inspired by the bold subscription-service aesthetic of Designjoy but customized for small businesses and growing brands.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Push this folder to GitHub and import it into Vercel.

## Edit key details

- Landing page content: `app/page.tsx`
- Global styles: `app/globals.css`
- Colors/theme: `tailwind.config.ts`
- Email CTA: search for `hello@flightmodestudio.co` in `app/page.tsx`

## Sections included

- Sticky nav
- Hero section
- Animated marquee
- Problem / solution
- How it works
- Benefits grid
- Pricing cards
- Campaign burst upsell
- Target audience
- FAQ
- Final CTA
